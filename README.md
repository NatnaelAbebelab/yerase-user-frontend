# Yerase User Frontend

A modern React-based frontend application for the Yerase user management system.

## 🚀 Features

- **User Authentication** - Secure login and registration
- **User Profile Management** - Edit and view user profiles
- **Responsive Design** - Mobile-first approach
- **Modern UI/UX** - Clean and intuitive interface
- **Real-time Updates** - Dynamic content updates
- **API Integration** - Seamless connection with backend services

## 🛠 Tech Stack

- **Frontend Framework**: React 18+
- **Language**: TypeScript
- **Styling**: CSS3/Sass or Tailwind CSS
- **State Management**: Redux Toolkit / Context API
- **Routing**: React Router
- **HTTP Client**: Axios
- **Build Tool**: Vite / Create React App
- **Package Manager**: npm/yarn

## 📋 Prerequisites

Before running this project, make sure you have the following installed:

- Node.js (version 16 or higher)
- npm or yarn package manager
- Git
